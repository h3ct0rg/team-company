# Entregables para la persona

Guarda aquí los resultados que el humano deba revisar, decidir o ejecutar: páginas HTML, documentos, hojas de cálculo, PDF u otros archivos útiles. Organiza por negocio o área cuando crezca el contenido.

El responsable del área crea y comparte directamente su propia página HTML cuando haga falta. Usa `templates/DELIVERABLE.html` como referencia visual, no como obligación de llenar cada sección. El CEO puede mantener una página de resumen y enlazar las entregas de las áreas.

No guardes aquí borradores internos, ni crees un archivo por cada mensaje. No sobrescribas entregables existentes; crea una versión nueva o pide aprobación si se requiere reemplazar uno.
