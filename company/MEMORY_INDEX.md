# Índice de memoria

La memoria conserva conocimiento útil para decisiones futuras. Guarda la información detallada en archivos temáticos y enlázala aquí. No copies conversaciones completas ni dupliques información sin necesidad.

## Reglas de memoria

- Prioriza hechos duraderos, decisiones aprobadas, preferencias, aprendizajes de experimentos y fuentes que respaldan afirmaciones.
- Cada entrada debe indicar fecha, negocio/área, tipo (hecho, decisión, supuesto o aprendizaje) y origen cuando aplique.
- Conserva la fuente original y su fecha de consulta para datos externos cambiantes.
- Si dos registros se contradicen, no elijas silenciosamente: registra el conflicto y pide aclaración si afecta el trabajo.
- Recupera solo los archivos relevantes para la tarea actual.

## Índice

| Tema | Archivo | Contenido |
|---|---|---|
| Registro de decisiones | `memory/DECISIONS.md` | Decisiones importantes, responsable, fecha y razón. |
| Investigación de mercado | `memory/RESEARCH.md` | Competidores, mercado, fuentes y evidencia por negocio. |
| Experimentos y aprendizajes | `memory/LEARNINGS.md` | Hipótesis probadas, resultados y próximos pasos. |

## Añadir memoria

Si aún no existe el archivo temático, créalo usando Markdown con títulos y fechas. Mantén una entrada breve en este índice para que pueda encontrarse por tema o palabra clave.
