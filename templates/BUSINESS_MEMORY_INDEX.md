# Índice de memoria del negocio

Este índice vive en `[empresa]/MEMORY_INDEX.md`. Guarda la información detallada en `[empresa]/memory/` y recupera solo lo necesario para cada tarea: lee este índice primero y abre solo el archivo que necesitas.

## Reglas

- Conserva decisiones duraderas, investigación, experimentos y aprendizajes útiles.
- No guardes conversaciones completas ni dupliques entregables.
- Cada registro indica fecha, tema, tipo (hecho, decisión, supuesto o aprendizaje) y fuente cuando aplique.
- En investigación externa, conserva el enlace, la fecha de consulta, qué respalda y sus limitaciones.
- Si dos registros se contradicen, señala el conflicto y pide aclaración si cambia una decisión importante.
- Si un archivo supera unas 300 líneas, divídelo por tema o período (por ejemplo, `RESEARCH-2026.md`) y actualiza este índice.
- Nunca guardes credenciales, claves, tokens ni datos personales sensibles.

## Índice

| Tema | Archivo dentro de `memory/` | Contenido |
|---|---|---|
| Decisiones | `memory/DECISIONS.md` | Decisiones, responsables, fechas y razones, incluidas altas y bajas de roles. |
| Investigación | `memory/RESEARCH.md` | Mercado, competencia, fuentes y evidencia. |
| Aprendizajes | `memory/LEARNINGS.md` | Experimentos, resultados observados y siguientes pasos. |
| Conexiones | `memory/CONEXIONES.md` | Servicios conectados con aprobación: alcance, rol, fecha y estado. |
| Herramientas | `memory/HERRAMIENTAS.md` | Herramientas en uso y su costo. |

Crea cada archivo temático cuando exista contenido útil para guardar. No es necesario crear documentos vacíos. Añade filas cuando un área cree un archivo nuevo.
